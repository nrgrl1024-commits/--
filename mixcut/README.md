# 门店混剪

内部使用的网页，**总部一个人给所有门店出片**：

```
导入文案 Excel（每行一家店）
  → 每段文案自动拆成一句一句，每句配一段画面：本店主播 / 本店空镜 / 通用镜头
  → 用主播复刻的声音，按这家店的方言逐句配音
  → 在编辑页逐句修改：文字、画面、顺序、语速；预览满意后点「确认」
  → 一次导出全部已确认的视频和封面
```

- 视频在你电脑的浏览器里剪，素材不会上传到服务器
- 服务器只存门店资料和配音，总部谁打开网址，看到的都是同一份
- 每条视频都会检查：本店主播至少出镜一次，总时长建议不超过 30 秒
- 不加 LOGO、不加片尾，右下角固定显示"内容由AI生成"（AI 合成的声音按规定必须标注）

## 每天怎么用

1. 打开网址，输入访问密码
2. **① 导入文案 Excel**。表头要有这几列，列名包含这些字就行：

   | 人物 | 蜂仔改写脚本 | 封面标题 |
   |---|---|---|
   | 合肥 许师傅 男 | 卫生间瓷砖旧了不用砸，…… | 合肥卫生间翻新不用砸 1天就能焕新 |

   「人物」按「城市 + 主播昵称」对应到门店；也可以直接写门店名。对不上的行，可以一键新建门店。
3. **② 选择素材文件夹**：

   ```
   素材/
   ├── 通用/              所有门店都能用的镜头，可以再分小文件夹：通用/卫生间/、通用/厨房/
   ├── 音乐/              背景音乐 mp3，每条视频随机挑一首（也可以指定）
   ├── 合肥大铺头店/       ← 文件夹名 = 门店名
   │   ├── 人物/          主播出镜：真人拍的，或即梦生成的（只用画面，不用原声）
   │   └── 空镜/          本店拍的门头、店内、施工现场
   └── 成都温江店/
       └── 人物/
   ```

   文件夹名、文件名里的词会当作标签：文案里提到"卫生间"，就优先用 `通用/卫生间/` 里的镜头。
4. 点开每家店：先点「生成配音」，逐句检查，不满意的就改字、换画面、调顺序；然后点「▶ 预览」，满意后点「确认这条」
5. 全部确认后点「导出全部已确认的视频」，再点「全部下载」。每家店会得到一个视频和一张封面图

导出时按视频的实际时长录制，**导出过程中不要切到别的窗口**。请用最新版 Chrome 或 Edge。

### 小技巧
- 字幕就是这句文案。字幕太长会自动分成两行，想自己决定在哪断行，就在那个位置打一个空格
- 改了文字或语速，那一句要重新生成配音（同样的句子服务器有缓存，不重复花钱）
- 改过的内容会保存在浏览器里，刷新页面不会丢；但素材文件夹要重新选一次

## 第一次设置：复刻主播的声音

1. 在「门店资料」页填好每家店的门店名、城市、主播昵称、方言
2. 让主播用手机录 **10–20 秒** 方言：找个安静的地方，不要背景音乐，随便说几句平时介绍翻新的话
3. 在这家店点「上传声音」，等状态变成「可用」，点「试听」
4. 主播本人要签**声音和肖像授权**

方言是通过阿里云 CosyVoice 的方言指令实现的，目前支持广东话、四川话、东北话、河南话、湖南话、陕西话、山东话、安徽话。**复刻出来的声音说方言地不地道，要每家店试听确认。**

## 部署到腾讯云

1. 买一台**轻量应用服务器**：2 核 2G 就够，系统选 Ubuntu 22.04，地域选离总部近的
2. 在控制台 → 防火墙，确认放行了 **TCP 80** 端口
3. 申请阿里云百炼的 API Key：在阿里云开通「大模型服务平台百炼」，然后创建 API Key（sk- 开头）。没有也可以先装，以后再填
4. 登录服务器，把代码放上去，然后运行：

   ```bash
   cd mixcut
   sudo bash install.sh
   ```

   按提示填访问密码、API Key、服务器网址，脚本会自动装好并设为开机自动运行。以后要改密码或补填 Key，再运行一次就行。
5. 浏览器打开 `http://服务器IP`，用户名随便填，密码就是刚才设置的访问密码

查看运行日志：`journalctl -u mixcut -f`

> 用 IP 访问不需要备案。以后想用域名访问，需要先在腾讯云给域名做 ICP 备案。

## 开发

```bash
pip install -r requirements.txt pytest
python -m pytest tests          # 后台测试
python server.py                # http://127.0.0.1:8000，没设 ACCESS_PASSWORD 时不要密码
```

| 环境变量 | 说明 |
|---|---|
| `ACCESS_PASSWORD` | 访问密码，不设就不要密码 |
| `DASHSCOPE_API_KEY` | 阿里云百炼 API Key，不设就不能复刻声音（其他功能照常，时长按字数估算） |
| `PUBLIC_BASE_URL` | 服务器网址，阿里云要从这里下载声音样本 |
| `TTS_MODEL` | 默认 `cosyvoice-v3-plus` |
| `MIXCUT_DATA` | 门店资料、声音样本、配音缓存放在哪，默认 `data/` |
