# 门店混剪（独立网页）

一个网页文件 `混剪.html`，用最新版 Chrome 或 Edge 双击打开就能用。不用安装、不用登录、不用填密钥，也不连飞书、豆包、企微，视频只在这台电脑里处理。

## 成片怎么剪

```
声音：本店主播的方言口播，从头到尾不断
画面：[主播 3 秒] → [素材 2.5 秒 ×3] → [主播 2 秒] → [素材 ×3] … → [主播 3 秒收尾]
```

- 没有口播的门店不会出片，所以每条成片一定有本店主播、一定是方言
- 素材原声会去掉，只留画面；本店空镜优先，不够再用通用素材，每条随机挑选
- 顶部标题默认是「城市 + 品牌」；主播来源选「即梦」的门店，右下角自动加"内容由AI生成"
- 成片长度 = 口播长度，竖屏 1080×1920

## 每天怎么用（总部 1 人）

1. 按下面的样子整理素材文件夹：

   ```
   素材/
   ├── 通用/              所有门店都能用的画面（施工、前后对比……）
   ├── 珠海香洲店/
   │   ├── 口播/          本店主播的方言口播（真人拍摄，或即梦生成后下载），一个视频出一条成片
   │   └── 空镜/          本店拍的空镜头（门头、店内、施工现场）
   └── 佛山禅城店/
       └── 口播/
   ```

   门店文件夹的名字要和网页里的门店名一致。

2. 打开 `混剪.html`，点「选择文件夹」选中「素材」
3. 第一次用时，在「门店资料」里给每家店补上城市、方言，以及主播来源（真人 / 即梦）。资料会自动保存，可以「导出备份」
4. 点「开始批量生成」，等全部完成后点「全部下载」

## 注意

- 按口播的实际时长实时录制，30 秒的口播大约 30 秒出片。**生成时不要切到别的窗口**
- 页面顶部出现黄色提示，说明这个浏览器导出的格式视频号可能不认，请更新 Chrome 或 Edge
- 出镜真人的形象、声音要有授权；即梦生成的视频必须保留"内容由AI生成"标识
