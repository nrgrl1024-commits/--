# 蜂仔翻新 · 门店短视频流水线

原来要用视频号、小云雀、飞书、即梦、剪辑软件分 6 步完成，现在只剩**两处人工**，其余全部自动：

| 步骤 | 谁来做 | 在哪里 |
|---|---|---|
| ① 找到热门视频，下载后上传 | **总部 1 人** | 飞书「母版」页 |
| ② 识别对标视频：口播文案、封面文案、镜头拆解（替代小云雀） | 自动 | |
| ③ 按每家门店的城市、称呼、方言改写文案、封面、即梦提示词、视频号发布文案 | 自动 | 各门店页 +「今日任务」页 |
| ④ 复制提示词到即梦，选好主播生成，把视频拖回同一行 | **同事 1 人** | 飞书「今日任务」页 |
| ⑤ 加标题、字幕（关键词高亮）、背景音乐、封面、AI 标识 | 自动 | 成片回写到门店页 |
| ⑥ 把成片、封面、发布文案发到门店企业微信群 | 自动 | 门店收到后直接发视频号 |

即梦暂时没有开放 API，所以第 ④ 步保留人工操作。以后如果能用 API 调用，只需要替换这一步。

## 每个人要做什么

**总部**
1. 在视频号刷到热门视频，下载成 mp4（视频号链接无法被系统直接读取，必须先下载成文件）
2. 在飞书「母版」页新加一行：填选题，把视频拖进「对标视频」，状态选「待分发」
3. 几分钟后，「脚本内容」「封面标题」「镜头分析」会自动填好，所有门店页都会多出一行

> 识别出来的内容不满意，可以直接改；「脚本内容」和「镜头分析」提前填好的话，系统就不会再识别。
> 「适用门店」不填表示发给全部门店；只发几家就写门店名，用逗号隔开。

**负责即梦的同事**：只看「今日任务」这一页
1. 每行是一家门店，写好了用哪个主播、复制哪段提示词
2. 建议分两轮：**先把所有行的提示词提交到即梦排队，再回头统一下载**，比一条一条等快很多
3. 下载后把视频拖进同一行的「生成视频」，几分钟后状态变成「已完成」，成片自动发到门店群

**门店**：在企业微信群里收到成片、封面和发布文案，下载后发布到视频号。历史视频都保存在飞书里自己门店的那一页。

## 加新门店

在「门店资料」页**加一行**就行，系统下一轮会自动给这家门店建好页面：

| 字段 | 必填 | 例子 | 说明 |
|---|---|---|---|
| 门店名称 | ✅ | 珠海香洲店 | 同时也是这家门店页面的名字 |
| 城市 | ✅ | 珠海 | 改写时替换城市名；顶部标题默认是「城市+蜂仔翻新团队」 |
| 即梦主播 | ✅ | 阿乐师傅 | 即梦里这家门店用的数字人，显示在「今日任务」里 |
| 企微群机器人 | 建议 | https://qyapi.weixin.qq.com/…key=… | 填了才会自动推送到门店群（见下文） |
| 启用 | ✅ | ☑ | 取消勾选后，这家门店不再分发 |
| 方言 | | 粤语 | 会写进即梦提示词 |
| 地方称呼 | | 街坊 | 口播里怎么称呼当地人 |
| 顶部标题 | | 珠海蜂仔翻新团队 | 需要跟默认不一样时才填 |
| 区域 / 品牌名 / 出镜角色 / 风格备注 | | | 可不填 |
| 数据表名称 | | | 只有页面名跟门店名不一样时才填 |

### 获取企业微信群机器人地址
1. 打开门店的企业微信群，点右上角「…」
2. 找到「消息推送」或「群机器人」→「添加」，名字填"视频助手"
3. 复制它的 **Webhook 地址**，填到这家门店的「企微群机器人」字段

注意：
- 群机器人发文件的上限是 20MB。成片超过时，系统会自动另存一份压缩版发到群里，飞书里保存的仍是高清原版
- 如果群里有外部微信用户，请先在企业微信里确认这个群能不能添加机器人

## 飞书表格结构

每家门店仍然是单独的一页，历史视频都记在自己那一页。另外有三页是总部用的：

```
多维表格
├── 门店资料    每家门店一行
├── 母版        总部上传对标视频
├── 今日任务    负责即梦的同事只看这页
├── 珠海香洲店  ← 你们原有的门店页，继续用
├── 佛山禅城店
└── ……
```

- 门店页原有的字段（文本、对标脚本内容、改写脚本内容、封面标题、对标视频、即梦AI提示词、生成视频）全部保留。系统会补上：日期、状态、母版、副标题、高亮词、成片、封面图、发布文案、已推送群、背景音乐、备注
- **系统只处理有「状态」的行**，以前手工做好的旧行不会被改动
- 系统自动填写的内容都可以手动改。比如对某句改写不满意，直接改「改写脚本内容」，剪辑时会按改后的文字出字幕
- 状态流转：`待改写 → 待生成 → 剪辑中 → 已完成`，出错时变成 `失败`，原因写在「备注」里
- 想重新改写：把门店页这一行的状态改回「待改写」，「今日任务」里对应的那行会同步更新

## 部署步骤

### 1. 飞书应用
1. 在[飞书开放平台](https://open.feishu.cn/app)创建**企业自建应用**，记下 App ID 和 App Secret
2. 在「权限管理」开通多维表格和云文档相关权限（`bitable:app`、`drive:drive`），然后发布应用版本
3. 打开多维表格，点右上角「···」，把菜单**往下滚**到「更多」→「添加文档应用」，把这个应用加进来，并给「可编辑」权限
   - 找不到这个选项时，用群授权：在开放平台给应用「添加应用能力」→「机器人」并重新发布；新建一个飞书群，在群设置「群机器人」里添加这个应用；再在多维表格右上角「分享」给这个群，权限选「可编辑」
4. 多维表格链接 `https://xxx.feishu.cn/base/XXXXXX?table=...` 里，`base/` 后面那一段就是 app_token
   - 如果链接是 `https://xxx.feishu.cn/wiki/...`（表格放在知识库里），这一串不能直接用，需要先把表格移到「云文档」里，或者联系开发者改为支持知识库

### 2. 豆包（火山方舟）
1. 在 www.volcengine.com 注册并完成实名认证，进入「火山方舟」控制台
2. 在「开通管理」里开通一个豆包模型。**要选能看图片的版本**（模型介绍里写着支持图片理解或视觉理解），识别对标视频要用到。同一个模型也可以用来改写
3. 在「API Key 管理」里创建 API Key
4. 在模型详情页复制 Model ID（如 `doubao-seed-xxx`），或者在「在线推理」里创建接入点，得到 `ep-xxx`

### 3. 安装运行

**推荐：一键安装。** 买一台国内云服务器，阿里云或腾讯云的「轻量应用服务器」就行：2 核 4G，系统选 Ubuntu 22.04。把项目代码放到服务器上，进入项目目录后运行：

```bash
sudo bash deploy/install.sh
```

脚本会自动完成：安装 ffmpeg 和中文字体 → 安装依赖 → 逐个提示你填写飞书和豆包的密钥 → 初始化飞书表格 → 设为开机自动运行。中途出错时，改正后重新运行即可。

装好后，查看运行日志：`journalctl -u fengzai-video -f`

**手动安装**（需要 Python 3.10 或更高版本）：

```bash
pip install -r requirements.txt
cp .env.example .env                  # 填入飞书和豆包的密钥
cp config.example.yaml config.yaml
python -m fengzai_video setup         # 建「门店资料」「母版」「今日任务」三页，给各门店页补字段
```

第一次建「门店资料」页时，会按现有的门店页预先填好门店：像「1安徽合肥大铺头(男)」这样的页面名，会自动拆成门店名称"安徽合肥大铺头"、城市"合肥"、区域"大铺头"、主播性别"男"。**城市是系统猜的，请逐个核对**，再补充即梦主播和企微群机器人。

把字体放进 `assets/fonts/`、背景音乐放进 `assets/music/`，然后在 config.yaml 里填字体名称。

### 4. 日常运行
```bash
python -m fengzai_video watch         # 常驻运行，每 2 分钟检查一次表格
```

## 不连飞书的本地测试

```bash
python -m fengzai_video local-analyze --video 对标视频.mp4          # 识别对标视频
python -m fengzai_video local-rewrite --city 佛山 --term 街坊 --dialect 粤语 --script "女业主：……"
python -m fengzai_video local-edit --video 即梦原片.mp4 --title 珠海蜂仔翻新团队 --script "女业主：……" --out out/成片.mp4
python -m pytest                                                   # 单元测试
```

## 可以调整的地方

| 想改什么 | 改哪里 |
|---|---|
| 识别对标视频的要求 | `prompts/analyze.md` |
| 改写规则、即梦提示词写法、发布文案 | `prompts/rewrite.md` |
| 字体、颜色、音乐音量、画质、底部声明 | `config.yaml` 的 `render` 部分 |
| 飞书字段名 | `config.yaml` 的 `fields` 部分 |

## 注意事项
- **字幕时间轴**：系统会检测原片里哪些时间段有人声，再按字数分配字幕。所以即梦提示词里 BGM 统一写成"无（后期统一添加）"，原片越干净，字幕对得越准
- **对标视频识别**：口播文案是从画面上的字幕读出来的。如果对标视频本身没有字幕，识别会不完整，需要手动补「脚本内容」
- **AI 标识**：按《人工智能生成合成内容标识办法》，AI 生成的视频要加显著标识，默认在右下角显示"内容由AI生成"
- **授权**：出镜真人的形象、声音要有书面授权；字体和音乐要用有商用授权的；参考热门视频时，只借鉴思路和结构，不要照搬别人的画面和原文
