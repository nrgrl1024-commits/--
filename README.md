# 蜂仔翻新 · 门店短视频流水线

把「找对标 → 改写脚本 → 写即梦提示词 → 即梦生成 → 剪辑」这几步串起来，统一在**飞书多维表格**里操作。

```
总部在「母版」表写 1 条母版（脚本 + 封面标题），状态设为「待分发」
        ↓ 自动
给 30 多家门店各建一行，豆包按城市、称呼、方言分别改写，填好：
改写脚本 / 封面标题 / 副标题 / 高亮词 / 即梦AI提示词
        ↓ 门店手动（约 2 分钟）
复制「即梦AI提示词」到即梦生成 → 下载视频 → 拖进「生成视频」字段
        ↓ 自动
加顶部标题、口播字幕（关键词高亮）、背景音乐、AI 标识
→ 输出成片 + 封面图，回写到「成片」「封面图」字段
```

即梦暂时没有开放 API，所以即梦这一步保留人工操作。以后如果能用 API 调用，只需要替换这一步，其他部分不用改。

## 飞书表格结构

运行 `setup` 会自动建好下面三张表。

**门店资料**（填一次，以后很少改）

| 字段 | 例子 | 说明 |
|---|---|---|
| 门店名称 | 珠海香洲店 | |
| 城市 / 区域 | 珠海 / 香洲 | 改写时会替换城市名 |
| 顶部标题 | 珠海蜂仔翻新团队 | 视频顶部的大标题；不填默认为「城市+品牌名+团队」 |
| 品牌名 | 蜂仔翻新 | |
| 地方称呼 | 街坊 | 口播里怎么称呼当地人 |
| 方言 | 粤语 | 会写进即梦提示词 |
| 出镜角色 | 女业主 + 男师傅 | |
| 风格备注 | 说话干脆、爱说"包你满意" | |
| 启用 | ☑ | 取消勾选后，这家门店不再分发 |

**母版**：选题、对标视频、脚本内容、封面标题、即梦提示词参考、适用门店（不填表示全部门店）、状态

**每日视频**：门店、母版、日期、状态、脚本内容、**改写脚本内容**、**封面标题**、**副标题**、**高亮词**、**即梦AI提示词**、生成视频、**成片**、**封面图**、背景音乐、备注

加粗的字段由系统自动填写，**都可以手动改**。比如对某句改写不满意，直接改「改写脚本内容」，剪辑时会按改后的文字出字幕。

「状态」字段的流转：`待改写 → 待生成 → 剪辑中 → 已完成`，出错时变成 `失败`，原因写在「备注」里。
- 想重新改写：把状态改回「待改写」
- 想重新剪辑：删掉「成片」里的文件，再把状态改成「待生成」

## 部署步骤

### 1. 准备飞书应用
1. 在[飞书开放平台](https://open.feishu.cn/app)创建**企业自建应用**，记下 App ID 和 App Secret
2. 在「权限管理」开通多维表格和云文档相关权限（`bitable:app`、`drive:drive`），然后发布应用版本
3. 打开多维表格，点右上角「…」→「更多」→「添加文档应用」，把这个应用加进来，并给「可编辑」权限
4. 多维表格链接 `https://xxx.feishu.cn/base/XXXXXX?table=...` 里，`base/` 后面那一段就是 app_token

> 如果多维表格放在知识库（wiki）里，链接里的 token 不能直接用，建议把表格放在「云文档」里。

### 2. 准备豆包（火山方舟）
在火山方舟控制台开通一个豆包文本模型，拿到 API Key 和模型名（或推理接入点 ID）。

### 3. 安装运行
需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
cp .env.example .env                  # 填入上面拿到的密钥
cp config.example.yaml config.yaml
python -m fengzai_video setup         # 自动建三张表，把输出的 table_id 填进 config.yaml
```

把字体放进 `assets/fonts/`、背景音乐放进 `assets/music/`，然后在 config.yaml 里填字体名称。详见这两个文件夹里的 README。

### 4. 日常运行
```bash
python -m fengzai_video watch         # 常驻运行，每 2 分钟检查一次表格
```
也可以用定时任务：`*/5 * * * * cd /path/to/repo && python -m fengzai_video run`

服务器用普通云主机就行（2 核 4G 起），剪一条 15 秒的视频大约 30 秒。

## 不连飞书的本地测试

```bash
# 测试 AI 改写（需要豆包密钥）
python -m fengzai_video local-rewrite --city 佛山 --term 街坊 --dialect 粤语 \
  --script "女业主：珠海的街坊们别再踩坑啦！……" --cover "珠海厨房翻新 人工材料全包不用搬家"

# 测试自动剪辑（只需要 ffmpeg）
python -m fengzai_video local-edit --video 即梦原片.mp4 --title 珠海蜂仔翻新团队 \
  --subtitle "厨房翻新 人工材料全包不用搬家" --cover "珠海厨房翻新 人工材料全包不用搬家" \
  --highlights "珠海,踩坑,几千块,老乡" --script "女业主：……\n男师傅：……" --out out/成片.mp4

python -m pytest                       # 运行单元测试
```

## 可以调整的地方

| 想改什么 | 改哪里 |
|---|---|
| 改写规则、提示词写法、示例 | `prompts/rewrite.md`（纯文字，直接改） |
| 字体、颜色、音乐音量、画质、底部声明 | `config.yaml` 的 `render` 部分 |
| 飞书字段名 | `config.yaml` 的 `fields` 部分 |

## 注意事项
- **字幕时间轴**：系统会检测原片里哪些时间段有人声，再按字数分配字幕。所以即梦提示词里 BGM 统一写成"无（后期统一添加）"，原片越干净，字幕对得越准
- **AI 标识**：按《人工智能生成合成内容标识办法》，AI 生成的视频要加显著标识，默认在右下角显示"内容由AI生成"
- **授权**：出镜真人的形象、声音都要有书面授权；字体和音乐要用有商用授权的
